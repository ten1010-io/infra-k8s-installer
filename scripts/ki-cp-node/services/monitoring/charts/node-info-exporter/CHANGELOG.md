# Changelog

모든 주요 변경 사항이 이 파일에 기록됩니다.

## [0.1.6] - 2025-06-24

### 기술적 변경
- Python 3.8 버전 호환성을 위해 타입 힌트를 `typing` 모듈을 사용하도록 수정

## [0.1.5] - 2025-06-23

### 변경사항
- 하드웨어 정보 누락 시 안전하게 처리하도록 개선
  - 메모리, 디스크, GPU 정보 수집 시 특정 사양(크기, 모델명 등)이 누락되어도 "N/A", "Unknown" 등으로 표기하여 스크립트 중단 방지

### 기술적 변경
- `memory_info`, `disk_info`, `gpu_info` 함수에서 `get()` 메서드와 `isinstance`를 사용해 값의 존재 및 타입 확인
- 일부 하드웨어 구성에서 정보 수집이 실패하던 문제 해결 및 안정성 향상

## [0.1.4] - 2025-06-18

### 변경사항
- 하드웨어 정보 수집 함수들의 예외 처리 개선
  - memory_info, disk_info, network_info 함수에 예외 처리 추가
  - 개별 항목 처리 시 오류 발생해도 다른 항목 수집 계속 진행

### 기술적 변경
- lshw 명령어 실행 실패 시 빈 리스트 반환
- JSON 파싱 실패 시 빈 리스트 반환
- 개별 하드웨어 항목 처리 실패 시 해당 항목만 건너뛰도록 개선

### 도커 이미지
- asdfry/node-info-exporter:20250618

## [0.1.3] - 2025-06-14

### 변경사항
- GPU 드라이버 버전 정보 수집 기능 추가
  - NVIDIA 드라이버 버전과 CUDA 버전 정보 수집
  - 하드웨어 정보에 driver_version 필드 추가

### 기술적 변경
- pynvml 라이브러리를 사용하여 드라이버 버전 정보 수집
- 버전 정보를 문자열 형식으로 변환 (예: 12040 -> 12.0.40)

### 도커 이미지
- asdfry/node-info-exporter:20250614-v2
