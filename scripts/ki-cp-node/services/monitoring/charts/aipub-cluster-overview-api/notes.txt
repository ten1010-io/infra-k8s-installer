아래 명령어로 배포 상태를 확인할 수 있습니다.

---

Helm 릴리스 상태
$ helm status {{ .Release.Name }} -n {{ .Release.Namespace }}

파드 상태 확인
$ kubectl get pods -n {{ .Release.Namespace }} -l app={{ .Release.Name }}

서비스 확인
$ kubectl get svc -n {{ .Release.Namespace }}

인그레스 확인
$ kubectl get ingress -n {{ .Release.Namespace }}

로그 확인
$ kubectl logs -n {{ .Release.Namespace }} -l app={{ .Release.Name }}

---

https://{{ .Values.hostname }}/docs

(인증서 및 TLS 설정에 따라 URL은 다를 수 있습니다.)
