cat /etc/os-release를 통해 해당 노드의 OS를 확인합니다.

다음 경우에 따라 특정 경로에 해당 인증서를 위치시킵니다.

- RHEL: /etc/pki/ca-trust/source/anchors/ 디렉토리
- Ubuntu: /usr/local/share/ca-certificates/ 디렉토리

다음 경우에 따라 명령어를 수행하여 인증서를 등록합니다.

- RHEL: sudo update-ca-trust
- Ubuntu: sudo update-ca-certificates
sudo systemctl restart containerd 명령어를 통해 containerd를 재시작합니다.
